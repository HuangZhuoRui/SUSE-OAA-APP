关于青蟹

跨平台教务辅助应用

青蟹（Project OAA）是由四川轻化工大学开放原子开源协会（SUSE OAA）项目部自主研发的跨平台教务辅助应用。 通过对接学校教务系统与 OAA 后端服务，将课表、成绩、考试、GPA 计算、教学计划、校园公告、打卡签到等常用教务功能聚合到一起， 用更现代、更流畅的方式替代繁琐的教务网页操作。

应用基于 Kotlin Multiplatform + Compose Multiplatform 构建，一套代码同时覆盖 Android、iOS 与 Desktop 三端。

常见问题

遇到问题，可以先看看这里

Q登录时账号密码安全吗？

登录密码在传输前使用 RSA 公钥加密，配合全程 HTTPS 传输；登录凭证仅保存在设备本地，青蟹不会将你的教务密码上传到第三方服务器。

Q忘记教务系统密码怎么办？

教务账号由学校统一管理，青蟹本身不提供密码找回功能，请通过学校教务处或官方教务系统的找回入口重置密码。

Q打卡签到时验证码识别失败怎么办？

应用内置了自动验证码识别功能，遇到识别失败可以重试或手动输入验证码；如果频繁失败，欢迎通过下方渠道反馈，帮助我们持续优化识别模型。

Q课表 / 成绩数据不是最新的怎么办？

应用会在本地缓存课表、成绩等数据以支持离线查看，下拉刷新或重新进入对应页面即可从教务系统同步最新数据。

Q如何反馈 Bug 或提出建议？

最推荐的方式是在 GitHub Issues 中提交问题，附上你的设备型号、系统版本和复现步骤；也可以通过下方邮箱联系我们。
